Before you jump in.

Is this an emulator?

The goal is a native Windows x64 implementation in Rust, with no PSP CPU emulator in the runtime. It is not yet a complete static translation or a finished replacement for the original game.

Which game copy is supported?

Research targets the European PSP release ULES-01347, version 1.01. Supply your own legally obtained ISO. No game files or texture packs are distributed with the project.

When can I play it?

There is no public playable download or announced release date. The current milestone is a local development prototype, with substantial work remaining.

Is this an official Rockstar project?

No. ReGTA CTW is an independent fan research project, not affiliated with or endorsed by Rockstar Games or Take-Two Interactive.
